# Corpus data and licensing

Application MIT does not relicense these assets. `manifests/sources.json` records immutable Git revisions (or retrieval version plus hash for BSB), upstream file URLs, full-input SHA-256, sample SHA-256, included/excluded fields, attribution, license paths and coverage. `samples/` are real source excerpts, not invented fixtures. Synthetic edge cases exist only in package tests. `generated/` and `downloads/` are ignored build products.

Audited 2026-10-26 against actual downloaded source bytes and notices:

- **SBLGNT:** publisher repository [LogosBible/SBLGNT](https://github.com/LogosBible/SBLGNT), revision `d7f35adca9ec410e1d1499c63b4dd989d76c8d4d`, `data/sblgnt/text/Matt.txt`. Its pinned LICENSE is CC BY 4.0 (bundled in `licenses/sblgnt.txt`), superseding the old restrictive license sometimes quoted elsewhere. Extracted the exact `Matt 28:19` line without apparatus changes. Attribution: *The Greek New Testament: SBL Edition*, Michael W. Holmes; © 2010 Society of Biblical Literature and Logos Bible Software.
- **Macula Greek:** [Clear-Bible/macula-greek](https://github.com/Clear-Bible/macula-greek), revision `8423afe47b9e8f24b7772e808af45c7159a6fe7e`, `SBLGNT/lowfat/01-matthew.xml`. Pinned LICENSE.md identifies CC BY 4.0 syntax/morphology/referents, SBLGNT text, and public-domain Berean `gloss`. Sample keeps only words whose ref begins `MAT 28:19!`, their syntax ancestor groups, and the explicit allowlist in `src/bible.ts`. Original XML declaration/formatting changed during extraction. UBS `ln`/`domain`, Cherith `english`/`mandarin`, and other attributes removed. License notice retained separately; no prohibited dataset fields are bundled. Attribution: “MACULA Greek Linguistic Datasets, available at https://github.com/Clear-Bible/macula-greek/”, © 2022–2024 Biblica, Inc.
- **BSB:** exact Matthew 28:19 line from the [publisher's text download](https://bereanbible.com/bsb.txt), linked from its [downloads page](https://berean.bible/downloads.htm). [Publisher license notice](https://berean.bible/licensing.htm) dedicates Bible text to the public domain as of April 30, 2023. The full text's initial public-domain notice was inspected. Bible text only; translation tables have not been audited or bundled. Mutable upstream URL is pinned by full-file checksum, with excerpt independently checksummed.
- **reformed-retrieval:** read-only local checkout and [upstream](https://github.com/kadencartwright/reformed-retrieval), revision `808956974894a625f84160761bc3fa9852d662e1`. Read `LICENSING.md`, `TRANSLATION_POLICY.md`, and `MANIFEST.sha256`. CC0 is confined to project-authored completed English paths. Historical work public-domain status does not automatically license modern normalized transcriptions/metadata. Those files are excluded. `manifests/reformed-retrieval.json` pins the revision and checksum-manifest digest. `reception-sample.json` pins one eligible English file's exact checksum, matching its upstream MANIFEST entry. Bundled CC0 legal text is `licenses/reformed-retrieval-CC0.txt`. Default sample is Calvin's 13 November 1561 baptism advice, with actual CO X/1 printed pages 214–215, labeled AI-assisted/unreviewed. The Latin is linked upstream rather than redistributed.

No TTESV, commercial Bible text, UBS domains, CC BY-SA or NC optional packs are bundled. License files apply at their documented scope only. This per-file audit does not certify unexamined upstream datasets, translations, editorial claims or scholarly accuracy.
